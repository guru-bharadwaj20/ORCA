# orca-vscode

VS Code extension for [ORCA](../README.md) — drive the clone → detect → approve →
containerize → self-heal flow from inside the editor, reusing the `orca-cli` core
(no reimplementation).

> **Status:** scaffolded in Phase 2 as an npm-workspace member. The extension itself
> (manifest, commands, plan webview, settings/secrets, full run) is built in Phases
> 3–7. There is nothing to run here yet.
